# AP Classroom Toolkit

A browser extension that enhances AP Classroom with improved navigation and interaction features.

## Features

- **Arrow Key Navigation**: Navigate between questions using arrow keys
- **Number Key Selection**: Quickly select answers using number keys
- **Performance Navigation**: Optimized navigation for better performance
- **Question Copy**: Copy questions for easier reference

## Installation

1. Clone or download this repository
2. Open your browser (Chrome/Edge/Brave)
3. Navigate to `chrome://extensions/`
4. Enable "Developer mode" in the top right
5. Click "Load unpacked"
6. Select the folder containing this extension

## Usage

Once installed, the extension will automatically activate on AP Classroom pages (https://apclassroom.collegeboard.org/*).

### Keyboard Shortcuts

- **Arrow Keys**: Navigate between questions
- **Number Keys (1-5)**: Select answer options quickly
